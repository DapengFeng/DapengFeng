# Profile maintenance

The profile uses native GitHub Markdown and disclosure sections, plus four local
SVG terminal headers. The English README contains English profile copy; the
Chinese translation lives in `README.zh-CN.md`. Original commit titles are kept
verbatim in either language.

## Refreshing recent commits

`.github/workflows/recent-commits.yml` refreshes the activity log hourly, at minute
17. It also runs when its source files change on `main`, or when started manually
under **Actions → Recent public commits → Run workflow**. The workflow must be on
the default branch before its schedule becomes active.

The updater checks the 20 most recently pushed eligible public repositories owned
by `DapengFeng`, including forks. It reads up to five commits per default branch
and keeps the five newest commits authored by that GitHub account. Private and
disabled repositories, commits by other authors, and this profile repository are
excluded. Excluding the profile prevents generated graphics and activity refreshes
from filling the feed. This is a bounded default-branch feed, not an exhaustive
record of contributions across organizations or feature branches.

The GitHub-provided `GITHUB_TOKEN` is sufficient; no additional secret is needed.
Only the marked activity blocks in both READMEs and `data/recent-commits.json` are
updated. An API or validation failure leaves the previous snapshot intact. A run
with unchanged activity does not create a commit. Dates use UTC+08:00.

GitHub schedules can be delayed, so this is an hourly refresh rather than an
instant cross-repository webhook. See [GitHub's schedule documentation](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).

To refresh locally, with an optional `GITHUB_TOKEN` for higher API rate limits:

```sh
python3 -B scripts/update_recent_commits.py --user DapengFeng
python3 -B -m unittest discover -s tests -p 'test_recent_commits.py'
```

## Editing the design

Edit the terminal copy and theme colors in `scripts/render-profile-hero.py`, then
regenerate the desktop and mobile headers:

```sh
python3 scripts/render-profile-hero.py
```

Update ordinary README copy outside the `RECENT_COMMITS` markers. Keep the markers
exactly once per README; the updater refuses ambiguous or missing markers. Project
links and the hidden debug log use native `<details>` sections and work without
JavaScript or an external image service.

## Active assets and workflows

- `assets/profile/`: four terminal headers generated by `render-profile-hero.py`.
- `assets/css/github-markdown.css`: styling for local README previews.
- `profile-snake-contrib/`: the contribution-snake easter egg, refreshed daily by
  `.github/workflows/snake.yaml`.
- `data/recent-commits.json`: the public commit snapshot refreshed by
  `.github/workflows/recent-commits.yml`.

The previous decorative images, PSD, Metrics cards, and 3D contribution charts
have been removed, together with their Metrics and 3D chart workflows. Their
committed versions remain available in Git history.
